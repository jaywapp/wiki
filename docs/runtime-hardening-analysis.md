# 웹 리더 성능·오류 방어 분석

orchestrator: Codex

기존 미커밋 웹 리더와 문서 변경은 보존한다. 사용자 요청은 동작 보존 성능·테스트·오류 방어이며 화면 디자인은 변경하지 않는다. 검색 입력마다 전체 본문을 정규화하고 정렬 비교마다 날짜 파싱·localeCompare 옵션 처리를 반복한다. localStorage에 JSON null이 있으면 설정 읽기 이후 접근에서 초기 화면이 실패한다.

검색·정렬 의미와 기존 파일을 보존하며 불필요한 재계산과 설정 파싱 경계만 개선한다. 빈값·잘못된 설정·검색/정렬·유해 링크의 기존 및 추가 node:test로 검증한다. 새 백엔드나 배포는 필요하지 않다.
