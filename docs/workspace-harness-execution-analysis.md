## 결정

- Q-01: 권장 경로인 새 관리 워커를 사용하고 기존 수동 세션은 보존한다.
- Q-02: 구현 원본 저장소 선택을 질문한 뒤 사용자가 '이어서' 진행을 지시했다. 별도 위치 지정이 없어 권장한 `D:\work\workspace-harness`에 로컬 저장소를 준비한다는 가정을 알리고 진행했다. 원격 저장소 생성·공개 범위는 미지정이다.
- Q-03: 루트의 자동 답변은 이미 확정된 요구사항을 전달하는 범위로 제한한다. 새 권한·범위 확대는 승인으로 추정하지 않는다.
- Q-04: 첫 구현은 exec/resume. 실험적 실시간 App Server/TUI adapter는 조건부 후속 범위다.
- Q-05: pilot는 프로젝트 1개·동시 1작업이다. 확장 단계의 실행 한도는 명시적인 설정으로 제공하며 무제한 실행을 기본값으로 삼지 않는다.

## 진행 원칙

기존 기능 재사용과 계약 검토는 독립 읽기 전용 조사로 병렬 수행한다. 전송 왕복 pilot 성공 후 코어 계약을 고정하고 ExecAdapter와 질문·루트 도구를 파일 경계별로 병렬 구현한다. 실제 완료와 검증하지 못한 부분을 구분한다.
