# 광고 수익 앱 공장 설계

**날짜:** 2026-06-12  
**목표:** 서버 없이 유지보수 비용 최소화, 광고 수익 모델로 월 30~50만원 달성

---

## 개요

서버 없이 배포 가능한 웹/앱을 대량으로 만들고, 광고(AdSense, AdMob)로 수익화하는 구조.  
웹으로 빠르게 검증하고, 잘 되는 것만 Flutter 앱으로 포팅해 광고 단가를 높인다.

**핵심 원칙:**
- 서버 비용 0원 (Vercel 무료 / Google Play 배포만)
- 유지보수 최소화 (정적 앱, 외부 API 의존 없음)
- 빠른 폐기 — 안 되는 건 방치 (비용 없으므로 OK)
- AI가 코드/콘텐츠 생산, 사람은 기획과 배포만

---

## 전체 전략 구조

```
Phase 1 — Web 검증기          Phase 2 — 앱 수익화
──────────────────────        ──────────────────────
아이디어 후보 목록              잘 되는 웹 툴 선별
      ↓                               ↓
AI로 빠르게 웹툴 생성           Flutter로 포팅
      ↓                               ↓
Vercel 무료 배포               Google Play 배포
      ↓                               ↓
AdSense 광고 삽입              AdMob 리워드 광고
      ↓                               ↓
트래픽/수익 측정 → 잘 됨? → 앱으로 확장
                   안 됨? → 다음 후보
```

## Phase 1: Web 도구 공장

### 기술 스택
- **React + Vite** — 빌드 빠름, 정적 배포 가능
- **Tailwind CSS** — 디자인 빠르게
- **Vercel** — push하면 자동 배포, 무료
- **Google AdSense** — 승인 1회로 모든 사이트 적용

### AI 생산 파이프라인
```
1. 아이디어 입력   "월세 vs 전세 비교 계산기"
        ↓
2. Claude 프롬프트 "React + Tailwind로 만들어줘, AdSense 광고 1개 포함"
        ↓
3. 코드 복붙 → 새 Vercel 프로젝트 배포
        ↓
4. 도메인 연결     tool-name.vercel.app (무료)
        ↓
5. AdSense 스니펫  <head>에 삽입
```

### 만들기 좋은 툴 유형 (SEO 트래픽 있는 것)
- **계산기류:** 대출이자, 실수령액, BMI, 적금 만기
- **변환기류:** 단위변환, 날짜계산, 파일변환
- **생성기류:** 닉네임, 비밀번호, 색상 팔레트
- **퀴즈류:** 상식, 심리테스트, MBTI 변형

### 목표
월 2~4개 배포 → 3개월 후 10개 운영 → AdSense 수익 확인

## Phase 2: Flutter 앱 공장

### 진입 조건
웹에서 특정 카테고리가 트래픽/수익 나올 때 → 해당 카테고리만 앱으로 포팅

### 기술 스택
- **Flutter** — Android/iOS 동시 배포
- **Google AdMob** — 배너 + 리워드 광고
- **google_mobile_ads** 패키지
- **SharedPreferences** — 로컬 데이터 저장 (외부 API 없음)

### 광고 삽입 패턴
| 사용자 행동 | 광고 트리거 |
|------------|------------|
| 결과 보기 전 | 리워드 광고 시청 후 잠금 해제 |
| 고급 기능 사용 | 리워드 광고 시청 후 활성화 |
| 앱 실행 시 | 배너 광고 (하단 고정) |
| 화면 전환 시 | 전면 광고 (3~5회에 1번) |

### 앱당 구조
- 화면 3~5개
- 광고 포인트 2~3개
- 외부 API 없음
- 데이터는 로컬 저장

**Flutter 앱 1개 생산 목표: 3~5일** (웹 검증된 아이디어 포팅이므로 기획 시간 없음)

### AI 연결 (선택적 확장)
필요 시 사용자가 OpenAI/Claude/Gemini API 키를 입력하면 AI 기능 활성화.  
키는 localStorage/SharedPreferences에만 저장 (서버 불필요).

## 수익화 전략

### 수익 구조 계산
| 채널 | 단가 | 월 목표 수익 | 필요 조건 |
|------|------|------------|---------|
| AdSense (웹) | RPM $1~3 | ~5만원 | 월 5만 페이지뷰 |
| AdMob 배너 | RPM $0.5~1 | ~5만원 | 앱 5개 × DAU 200 |
| AdMob 리워드 | RPM $5~15 | ~20만원 | 앱 5개 × 일 300뷰 |

### 로드맵
```
1~2개월   웹 툴 10개 배포, AdSense 승인
           → 예상 수익: 0~5만원 (검증 단계)

3~4개월   잘 되는 웹 툴 3개 Flutter 포팅
           → 예상 수익: 10~20만원

5~6개월   앱 5~8개 운영, 리워드 광고 최적화
           → 예상 수익: 30~50만원
```

### 핵심 레버
- 리워드 광고가 수익의 70%를 담당 → 앱에 집중
- 웹은 "검증 + 트래픽 유입" 역할
- 앱 안에서 "광고 보면 잠금 해제" 포인트 2개 이상 설계

## 대량 생산 파이프라인

### 아이디어 발굴 → 배포 표준 흐름

```
① 아이디어 검증 (30분)
   Google Trends / 네이버 검색량 확인
   이미 있는 앱? → 있어도 OK, 없으면 더 좋음

② AI로 웹 버전 생성 (2~4시간)
   프롬프트: "React + Tailwind로 [툴명] 만들어줘.
   광고 슬롯 2개 포함, 외부 API 없이 구현"

③ Vercel 배포 (10분)
   GitHub push → 자동 배포 → AdSense 스니펫 삽입

④ 2주 모니터링
   방문자 100명/일 이상? → Flutter 포팅 후보
   아니면?             → 방치 (비용 0원이므로 OK)

⑤ Flutter 포팅 (3~5일)
   웹 로직 이식 → AdMob 리워드 광고 2~3곳 삽입 → Google Play 배포
```

### 생산성 원칙
- 툴당 커스텀 최소화 — AI 생성 코드 70% 그대로 사용
- 디자인 통일 — 컴포넌트 라이브러리 1개 고정 (shadcn 또는 MUI)
- 배포 자동화 — GitHub push = 즉시 배포
