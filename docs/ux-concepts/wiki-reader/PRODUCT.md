# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

jaywapp: GitHub에 모은 개발 자료를 더 편하게 검색하고 읽으려는 사용자.

## Product Purpose

기존 Markdown 자료를 트리 또는 목록으로 탐색하고 필터·정렬·검색으로 필요한 문서를 찾는다.

## Stack

운영 스택은 미확정. 현재는 사용자 저장소 지침에 명시된 실행 가능한 화면 샘플 3종만 작성한다.

## Capabilities and Constraints

원본은 사용자가 제공한 github.com/jaywapp/wiki. 문서 기준 브랜치는 질문 중이다. 화면 선택 전 실제 문서 연동이나 운영 구현을 진행하지 않는다. 샘플은 공통된 시연용 소수 자료만 사용한다. 검색, 트리, 목록, 필터, 정렬, 본문 읽기를 모든 샘플에서 보여 준다.
