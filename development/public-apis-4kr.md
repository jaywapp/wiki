# public-apis-4Kr — 한국 서비스용 Public API 모음

> 한국에서 개발자가 활용할 수 있는 공개 API를 분야별로 정리한 오픈소스 카탈로그.

- 원본: https://github.com/yybmion/public-apis-4Kr
- 라이선스: MIT
- 주 언어: Python
- 확인 기준: 2026-09-04

## 개요

`public-apis-4Kr`는 한국 서비스와 개발 환경에서 활용 가능한 Public API를 체계적으로 모아둔 저장소다. 공공데이터뿐 아니라 국내 개발에서 유용한 여러 API/리소스를 한곳에서 탐색하기 위한 레퍼런스로 활용할 수 있다.

README 기준 한국 API 및 리소스 300개 이상과 별도의 글로벌 Public API 780개 이상을 제공한다. 링크 상태를 검사하는 GitHub Actions 워크플로도 운영한다.

## 눈여겨볼 점

- 국내 서비스 개발 시 API 탐색의 시작점으로 사용하기 좋다.
- 공공데이터포털 API를 포함해 분야별 공개 API를 빠르게 찾을 수 있다.
- README에 최신 업데이트 기준일을 명시하고 지속적으로 목록을 관리한다.
- 한국어/영어 문서와 글로벌 API 목록을 함께 제공한다.

## 대표적인 공공데이터 API

2026년 6월 활용신청 상위권에는 다음과 같은 API가 포함되어 있다.

- 기상청 단기예보 조회
- 조달청 나라장터 입찰공고
- 국토교통부 아파트 매매 실거래가
- 국세청 사업자등록정보 진위확인 및 상태조회
- 한국천문연구원 특일 정보
- 국토교통부 자동차종합정보
- 한국수출입은행 환율 정보
- 한국관광공사 관광정보
- 한국환경공단 에어코리아 대기오염정보
- 금융위원회 주식시세정보

## 활용 아이디어

### 개발/사내 도구

새로운 기능을 만들 때 외부 데이터가 필요하면 개별 API를 검색하기 전에 이 저장소를 카탈로그처럼 조회할 수 있다. 특히 날씨, 주소, 부동산, 금융, 관광, 사업자 정보처럼 국내 데이터 의존도가 높은 기능에 유용하다.

### AI 에이전트 / MCP

API 목록을 에이전트가 검색 가능한 데이터셋으로 변환하면, 사용자의 요청에 따라 적절한 국내 API를 찾아 추천하거나 API 연동 코드를 생성하는 도구로 확장할 수 있다.

예를 들어 다음 흐름을 구성할 수 있다.

`사용자 요구사항 → API 카탈로그 검색 → 후보 API 선택 → 인증 방식 확인 → 호출 코드/Tool 생성`

### 내부 API Registry

저장소 데이터를 주기적으로 가져와 사내에서 사용 가능한 API Registry를 만들고 다음 메타데이터를 추가 관리하는 것도 가능하다.

- API 이름/분야
- 제공 기관
- 인증 필요 여부
- REST/LINK 등 인터페이스 유형
- 사내 사용 사례
- 담당 프로젝트
- 마지막 검증일

## 평가

단순 링크 모음이라기보다 **한국 개발 환경에 특화된 Public API 인덱스**라는 점이 핵심이다. 새로운 프로토타입이나 자동화 도구를 빠르게 만들 때 API 탐색 시간을 줄이는 레퍼런스로 가치가 높다.

특히 AI 에이전트가 외부 서비스를 연결하는 구조에서는 이 목록을 API discovery 데이터 소스로 활용할 가능성이 있다.
