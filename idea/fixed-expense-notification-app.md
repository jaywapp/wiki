# 고정지출 알림 앱

## 1. 한 줄 요약
급여별 예상·실제 실수령액과 직접 지정한 사용 기간의 반복 지출을 관리하고, 계획 가용금액과 미출금 현황을 Android 상시 알림에서 확인하는 앱.

## 2. 배경 및 문제
매월 출금되는 월세·보험·할부·카드값 등의 금액과 일정을 기억하기 어렵고, 급여가 들어와도 얼마를 쓸 수 있는지 바로 알기 어렵다. 실수령액과 일부 반복 지출은 매월 변동하며, 급여 입금일과 실제 예산을 사용하는 기간도 다를 수 있다. 모든 소비를 기록하는 가계부보다 급여·반복 지출·알림에 집중한다.

## 3. 목표
- 고정지출 누락과 출금 지연을 쉽게 발견한다.
- 급여별 사용 기간에 필요한 지출을 반영해 계획 가용금액을 확인한다.
- 예상치와 확정치를 구분하고, 급여·지출 수정 시 즉시 재계산한다.
- **MVP 검증 제안:** 날짜 경계·변동 금액·출금 상태 테스트 통과, 앱 재시작 후 데이터 유지, 알림 권한 허용 시 정보 갱신 확인.

## 4. 대상 사용자
매월 급여를 받으며 여러 반복 지출을 관리하는 Android 사용자. 복잡한 가계부 입력 없이 급여로 감당해야 할 지출과 남는 계획 예산을 확인하려는 사람.

## 5. 핵심 아이디어
### 급여
급여별로 식별명, 입금일, 예상 실수령액, 실제 실수령액, 사용 시작일·종료일을 저장한다. 급여일은 **수입 기록용**, 직접 설정한 사용 기간은 **지출 계산용**이다. 실제 급여 입력 전에는 예상 급여를, 입력 후에는 실제 급여를 적용한다. 과거 기록은 유지한다.

### 지출
반복 지출은 고정 금액(월세·할부 등)과 월별 변동 금액(카드값·관리비 등)을 지원한다. 변동 금액 미확정 시 직전 발생 금액을 예상치로 적용한다. 직전 금액이 없는 신규 항목은 **입력 필요**로 표시한다. 실제 금액이 확인되면 사용자가 수정한다.

### 계산
`계획 가용금액 = 해당 급여 적용액 - 해당 사용 기간에 예정된 지출 합계`

- 사용 기간은 시작일·종료일을 모두 포함한다.
- 급여 또는 지출 중 하나라도 예상치라면 계산 결과는 **예상**으로 표시한다.
- 실제 급여 및 모든 대상 지출 금액이 확정된 경우에만 **확정**으로 표시한다.
- 필수 금액 누락 시 계산이 불완전함을 경고하고 누락액을 확정 0원으로 취급하지 않는다.
- 출금 완료 체크는 **계획 가용금액을 변경하지 않으며**, 미출금액과 완료 건수만 변경한다.
- 계획 가용금액은 통장 잔액이나 소비 후 실제 남은 돈을 의미하지 않는다.

### 출금 상태
사용자가 직접 출금 완료를 체크하고 취소할 수 있다. 예정일이 지났는데 완료되지 않으면 미출금 상태를 유지하고 경고한다. **이전 사용 기간의 미출금은 이력 유지 + 별도 경고**, 다음 기간으로 자동 이월하거나 차감하지 않는다.

## 6. 주요 사용 흐름
1. 급여 입금일·예상액·사용 시작일·종료일 등록.
2. 고정/변동 반복 지출명·금액·출금 예정일 등록.
3. 사용 기간에 포함된 지출을 모아 계획 가용금액 계산.
4. Android 알림창에서 가용금액 상태, 미출금액, 다음 지출 확인.
5. 급여 입금 후 실제 실수령액 입력 → 재계산 및 알림 갱신.
6. 변동 지출 실제 금액 수정 → 재계산.
7. 실제 출금 후 완료 체크 → 미출금액·완료 건수 갱신.
8. 다음 급여를 별도로 등록하고 사용 기간 설정; 과거 미출금은 별도 경고.

## 7. 핵심 기능
| 기능 | 입력·처리 | 결과 | 우선순위 |
|---|---|---|---|
| 급여 관리 | 입금일, 예상/실제액, 사용 기간 등록·수정 | 급여별 예산 기준 | 필수 |
| 반복 지출 | 유형, 금액, 예정일 등록·수정·삭제 | 기간별 지출 발생 건 | 필수 |
| 변동액 예상 | 직전 금액 적용, 신규 미입력 감지 | 예상/입력 필요 표시 | 필수 |
| 계산 | 기간 내 발생 건 집계 | 예상/확정 계획 가용금액 | 필수 |
| 출금 확인 | 완료/취소 수동 체크 | 미출금액·완료 건수 갱신 | 필수 |
| 지연 경고 | 예정일 경과·미완료 확인 | 알림 강조 및 과거 이력 | 필수 |
| 상시 알림 | 현재 급여·기간·가용금액·다음 지출 표시 | 앱 열지 않고 확인 | 필수 |
| 기록 보존 | 급여·지출·출금 상태 영속 저장 | 과거 조회 및 재시작 복구 | 필수 |

## 8. 범위
### MVP
Android 앱, 급여별 사용 기간 직접 설정, 예상/실제 급여, 고정/변동 반복 지출, 직전 금액 예상 적용, 계획 가용금액, 수동 출금 체크, 지연·과거 미출금 경고, 상시 알림, 영속 저장.

### Later
홈 화면 위젯, 백업/복원, 은행·카드 연동, 실제 잔액 계산, 일반 소비 추적, 통계, 일일 사용 가능액, 복수 급여 통합, 자동 출금 확인.

### Out of Scope
은행 송금, 자동이체 실행, 결제 실행, 투자 관리, 전체 소비 자동 수집.

## 9. 결정된 사항
1. Android 우선, 알림창 상시 표시.
2. 계획 가용금액은 급여에서 해당 사용 기간의 전체 지출을 차감.
3. 출금 완료는 사용자 수동 체크; 계산값은 변경하지 않음.
4. 급여일은 수입 기록 기준, 급여별 직접 설정한 시작일·종료일은 지출 계산 기준.
5. 고정 금액과 월별 변동 금액 모두 지원.
6. 예정일 경과 미출금은 유지하고 강조.
7. 예상 급여와 실제 실수령액을 구분.
8. 미확정 변동 지출은 직전 금액을 예상치로 적용; 신규 항목은 입력 필요.
9. 이전 사용 기간 미출금은 이력 유지 및 별도 경고, 자동 이월 없음.

## 10. 미결정 사항
- 서로 다른 급여 사용 기간이 겹치거나 비는 경우의 허용·경고 정책.
- 29~31일 반복 예정일과 휴일 입금일 처리.
- 신규 변동 지출 금액 누락 시 가용금액 숫자 표시 수준.
- 실제 출금일이 예정일과 다를 때의 처리 및 과거 기록 수정 범위.
- Android 최소 버전, 알림 유지 구현, 권한 거부·재부팅·배터리 제약 대응.
- 로컬 저장 기술 및 데이터 백업 정책.

## 11. 위험 요소 및 대응
- **예상치 오인:** 예상/확정/입력 필요 상태를 명시한다.
- **중복 지출:** 기간 겹침 검증과 지출 발생 건 식별자를 설계한다.
- **과거 미출금의 실질 차감 누락:** 현재 계산에는 자동 반영하지 않고 별도 경고한다.
- **실제 잔액과 혼동:** '계획 가용금액'으로 표시한다.
- **Android 알림 제약:** 버전별 기술 검증 및 앱 내 대체 화면을 제공한다.
