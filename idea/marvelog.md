# Marvelog

## 1. 한 줄 요약

**“마블, 어디까지 봤어?”**를 한눈에 확인할 수 있는 마블 영상물 정주행 체크 서비스.

사용자는 MCU에 한정되지 않은 마블 기반 영화·드라마·애니메이션을 여러 정주행 관점으로 탐색하고 시청 상태를 기록하며, 자신의 진행률과 업적을 카카오톡 등으로 공유하고 지인과 비교할 수 있다.

## 2. 배경 및 문제

마블 영상물은 MCU 영화만 보더라도 작품 수가 많고, Disney+ 드라마·애니메이션·X-Men·Spider-Man 계열·Fantastic Four 등까지 확장하면 “무엇을 어떤 순서로 봐야 하는지”, “내가 어디까지 봤는지”를 기억하기 어렵다.

현재 사용자는 검색 결과, 블로그 정리, 위키, OTT 목록 등을 오가며 작품 순서를 확인해야 하고, 자신이 본 작품을 별도로 기억하거나 메모해야 한다. 또한 친구나 연인과 함께 정주행하려는 경우 서로 무엇을 봤는지 비교하는 과정도 번거롭다.

Marvelog는 단순 작품 정보 DB보다 **정주행 경로, 개인 기록, 진행률, 공유, 비교**에 집중한다. 하나의 작품 데이터를 여러 관점으로 재구성하고, 한 번 체크한 시청 상태가 모든 관점에 공통 반영되도록 하는 것이 핵심이다.

## 3. 목표

### 사용자 가치

- 마블 작품을 “다음에 무엇을 볼지” 고민하지 않고 정주행할 수 있다.
- 본 작품과 보지 않은 작품을 지속적으로 기록할 수 있다.
- MCU뿐 아니라 다양한 마블 세계관을 자신이 원하는 깊이까지 탐색할 수 있다.
- 진행률과 업적을 통해 정주행 자체에 성취감을 느낄 수 있다.
- 자신의 기록을 지인에게 공유하고 서로의 시청 상태를 비교할 수 있다.
- 두 사람이 함께 볼 다음 작품을 쉽게 찾을 수 있다.

### 조직/서비스 목표

초기에는 회원가입 없는 웹 서비스로 핵심 가치인 **“체크 → 진행률 → 공유”** 흐름이 실제로 사용되는지 검증한다.

### 성공 기준

정량 성공 기준은 아직 결정하지 않았다. MVP 설계 시 다음 후보를 기준으로 측정안을 정할 필요가 있다.

- 첫 방문 후 첫 작품 체크까지의 전환율
- 방문당 체크 작품 수
- 체크 기록을 만든 사용자 중 공유 스냅샷 생성 비율
- 공유 링크 유입자의 체크리스트 시작 비율
- 비교 기능 사용 비율
- 재방문율 및 기록 복구 사용률

## 4. 대상 사용자

### 마블 정주행 입문자

어떤 작품부터 어떤 순서로 봐야 할지 안내가 필요한 사용자. 핵심 작품 위주로 부담 없이 시작할 수 있어야 한다.

### 기존 마블 팬

이미 많은 작품을 봤지만 자신의 시청 현황을 한눈에 확인하거나 누락 작품을 찾고 싶은 사용자.

### 심화 정주행 사용자

MCU를 넘어 X-Men, Spider-Man 계열, 과거 실사 작품, 애니메이션 등 마블 영상물 전체를 탐색하고 싶은 사용자.

### 친구·연인과 함께 보는 사용자

서로의 시청 기록을 비교하고 둘 다 보지 않은 작품이나 함께 볼 다음 작품을 찾고 싶은 사용자.

## 5. 핵심 아이디어

### 하나의 작품 DB, 여러 정주행 View

작품은 DB에서 한 번만 관리하고, 관계·태그·정렬 데이터를 이용해 여러 관점으로 보여준다.

지원할 주요 관점은 다음과 같다.

- 공개순
- 세계관 내부 시간순
- 히어로별
- 세계관별
- 사가·페이즈별
- 시리즈·프랜차이즈별
- 전체 정복

예를 들어 《어벤져스: 엔드게임》을 공개순 화면에서 `봄`으로 체크하면 MCU 시간순, Avengers 시리즈, 관련 히어로 View에서도 동일한 상태가 즉시 반영된다.

### 정주행 깊이 모드

방대한 전체 목록을 처음부터 노출하지 않고 사용자가 원하는 깊이로 범위를 확장할 수 있도록 3단계 모드를 둔다.

- **Vibranium**: 핵심 실사 영화·주요 시리즈 중심의 기본 단계
- **Mjolnir**: Vibranium + 실사 드라마·주요 연계 작품·연계성이 높은 애니메이션까지 확장
- **Infinity**: Marvelog DB에 포함된 마블 원작 기반 영상물 전체를 대상으로 하는 심화 단계

첫 방문에서 모드 선택을 강제하지 않는다. 기본 체크리스트를 즉시 보여주고 상단 필터/모드 전환으로 범위를 바꾼다.

각 모드의 정확한 작품 포함 기준은 콘텐츠 DB 구축 과정에서 최종 정의한다.

### 게임화된 진행률과 업적

사용자가 단순 체크를 넘어 정주행 과정 자체에서 성취감을 느끼도록 전체/모드/세계관/히어로별 진행률과 Infinity Stone 기반 업적을 제공한다.

### 공유와 비교

사용자는 특정 시점의 시청 현황을 읽기 전용 스냅샷으로 생성해 카카오톡 등으로 공유할 수 있다. 공유받은 사람은 원본을 수정할 수 없으며 자신의 기록과 비교할 수 있다.

## 6. 주요 사용 흐름

### A. 첫 방문 및 기록 시작

1. Marvelog 접속
2. 별도 회원가입이나 온보딩 없이 기본 작품 목록 표시
3. 사용자가 본 작품을 바로 체크
4. 체크 직후 전체 및 현재 View 진행률 갱신
5. 필요 시 정주행 깊이 또는 View 변경

### B. 정주행 탐색

1. `공개순 / 시간순 / 히어로 / 세계관 / 사가·페이즈 / 시리즈` 중 관점 선택
2. 포스터 그리드 또는 리스트/타임라인 보기 선택
3. 현재 위치와 다음 작품 확인
4. 작품 상세에서 OTT·설명·평점 등 추가 정보 확인
5. 시청 후 상태 변경

### C. 개인 진행 현황 확인

1. 전체 시청 수와 진행률 확인
2. Vibranium / Mjolnir / Infinity별 달성률 확인
3. 세계관·히어로·시리즈별 진행률 확인
4. 획득한 Infinity Stone 및 다음 목표 확인

### D. 공유

1. 사용자가 공유 선택
2. 닉네임 입력 또는 기존 닉네임 사용
3. 현재 시점의 읽기 전용 스냅샷 생성
4. 공유 카드와 URL 생성
5. 카카오톡 등으로 전달
6. 이후 원본 기록이 바뀌어도 기존 스냅샷은 당시 상태 유지

### E. 친구 비교 및 같이 보기

1. 친구가 공유 링크 접속
2. 공유자의 진행률과 체크리스트 확인
3. `나도 체크해보기` 또는 `비교하기` 선택
4. 자신의 기록이 있으면 즉시 비교, 없으면 체크리스트 작성 유도
5. `둘 다 봄 / 나만 봄 / 상대만 봄 / 둘 다 안 봄`으로 비교
6. 둘이 함께 볼 다음 작품 후보 확인

### F. 기록 복구

1. 사용자가 `내 기록 보관하기` 선택
2. 실제 기록을 복구할 수 있는 비밀 복구 링크 생성
3. 사용자가 개인 메모나 카카오톡 나에게 보내기 등으로 보관
4. 다른 기기/브라우저에서 링크를 통해 기록 복구

공개용 공유 링크와 복구 링크는 완전히 분리한다.

## 7. 핵심 기능

### 7.1 작품 체크

가장 빈번한 핵심 액션이다. 포스터 그리드에서도 상세 화면 진입 없이 빠르게 상태를 변경할 수 있어야 한다.

상태:

- 안 봄
- 보는 중
- 봄
- 다시 보고 싶음: `봄` 여부와 별도의 부가 상태

우선순위: **MVP 필수**

### 7.2 정주행 깊이 전환

Vibranium / Mjolnir / Infinity 전환에 따라 대상 작품과 진행률을 함께 갱신한다.

우선순위: **MVP 필수**

### 7.3 다양한 정주행 View

- 공개순: 실제 최초 공개일 기준
- 시간순: 세계관별 사건 발생 순서. 서로 다른 세계관 전체를 하나의 시간축으로 합치지 않는다.
- 히어로별: 해당 캐릭터의 **주연작 기준**
- 세계관별
- 사가·페이즈별
- 시리즈·프랜차이즈별

우선순위: **MVP 핵심**

### 7.4 그리드 / 리스트 전환

기본은 포스터 그리드다. 순서가 중요한 공개순·시간순에서는 리스트 또는 타임라인 View가 유용하도록 설계한다.

우선순위: **MVP 필수**

### 7.5 작품 상세

다음 정보를 제공한다.

- 포스터
- 한글 제목 / 원제
- 공개 연도 / 공개일
- 러닝타임
- 콘텐츠 유형
- 세계관
- 시리즈 / 프랜차이즈
- 사가 / 페이즈
- 주연 히어로
- 간단한 설명
- 평점
- 대한민국 기준 시청 가능한 OTT
- OTT 정보 마지막 확인일
- 관련 정주행 순서

정보 탐색 서비스 자체가 목적은 아니므로 정주행 판단에 필요한 수준을 우선한다.

### 7.6 시리즈 체크

사용자가 시리즈의 체크 단위를 선택할 수 있어야 한다.

- 시즌 단위
- 에피소드 단위

기본 UX는 시즌 단위로 제공하고 필요 시 에피소드를 펼쳐 세부 체크할 수 있는 구조를 우선 검토한다.

### 7.7 진행률

최소 다음 수준의 진행률을 제공한다.

- 전체
- 정주행 깊이별
- 세계관별
- 히어로별
- 시리즈/프랜차이즈별

### 7.8 업적

Infinity Stone 6개를 정주행 업적에 연결한다.

- Power Stone
- Space Stone
- Reality Stone
- Soul Stone
- Time Stone
- Mind Stone

6개를 모두 획득하면 **Infinity Gauntlet** 업적을 제공한다.

전체 Infinity 콘텐츠 100% 달성에 대한 별도 최종 업적으로 **Stan Lee Club**을 두는 방향을 사용한다.

각 Stone의 정확한 획득 조건은 아직 결정하지 않는다.

### 7.9 공유 스냅샷

공유 시점의 진행 상태를 고정한 읽기 전용 데이터를 생성한다. 이후 원본 데이터 변경과 무관하게 당시 상태를 유지한다.

공유 페이지는 원본 사용자 데이터를 수정할 수 없다.

### 7.10 공유 카드

카카오톡 링크 미리보기 등에서 진행률과 업적이 매력적으로 보이는 공유 카드를 제공한다.

예시 정보:

- 닉네임
- Infinity 진행률
- 감상 작품 수 / 전체 작품 수
- Infinity Stones 획득 수
- `마블, 어디까지 봤어?`

포스터·캐릭터·Marvel 관련 시각 자산을 공유 카드에 직접 사용할 경우 저작권·상표 검토가 필요하다.

### 7.11 친구 비교

비교 결과는 최소 다음 네 그룹으로 제공한다.

- 둘 다 본 작품
- 나만 본 작품
- 상대만 본 작품
- 둘 다 안 본 작품

### 7.12 같이 볼 작품 추천

MVP에서는 복잡한 AI 추천보다 규칙 기반으로 시작한다.

후보 기준 예:

- 둘 다 안 본 작품
- 한 명이 `다시 보고 싶음`, 다른 한 명이 `안 봄`인 작품
- 두 사람 모두 진행 가능한 정주행 루트의 다음 작품

정확한 추천 우선순위는 미결정이다.

### 7.13 스포일러 방지

기본값은 스포일러 방지 ON이다.

미시청 작품에서는 이후 작품과의 관계, 주요 캐릭터 변화, 엔딩, 반전 등 핵심 정보를 최소화한다. 필요 시 사용자가 명시적으로 `스포일러 포함 정보 보기`를 선택할 수 있도록 한다.

## 8. 범위

### MVP

핵심 가치인 `정주행 → 체크 → 진행률 → 공유`를 검증하는 범위다.

- 자체 콘텐츠 DB
- 포스터 그리드
- 리스트/타임라인 보기
- 공개순
- 세계관별 시간순
- 히어로별(주연작 기준)
- 세계관별
- 사가·페이즈별
- 시리즈·프랜차이즈별
- Vibranium / Mjolnir / Infinity 깊이 모드
- 안 봄 / 보는 중 / 봄
- 다시 보고 싶음
- 시즌 단위 시리즈 체크
- 기본 진행률
- 닉네임
- 읽기 전용 공유 스냅샷
- 공유 카드
- 익명 사용자 기록
- 복구 링크
- 기본 친구 비교
- 기본 규칙 기반 같이 볼 작품 추천
- 기본 스포일러 방지
- 대한민국 기준 OTT 정보 + 확인일

단, 실제 구현 계획에서 MVP가 비대하다고 판단되면 `에피소드 단위 체크`, 세부 업적 연출, 고급 비교 UI를 후순위로 내리는 것을 우선 검토한다.

- 고급 추천
- 친구 관계 및 반복 비교
- 통계/연간 리포트
- 추가 업적 및 정주행 챌린지
- 공유 카드 커스터마이징
- 다국가 OTT
- 다국어

### Out of Scope

현재 아이디어 단계에서는 다음을 핵심 목표로 하지 않는다.

- IMDb/TMDB와 같은 범용 영화 정보 서비스
- 리뷰·커뮤니티 중심 SNS
- 실시간 채팅
- OTT 콘텐츠 직접 재생
- 초기 단계에서의 복잡한 AI 개인화 추천

## 9. 데이터 및 연동

### 자체 콘텐츠 DB

마블 영상물 메타데이터와 Marvelog 고유 큐레이션 데이터를 자체 DB로 관리한다.

주요 콘텐츠 유형:

- 영화
- 시리즈
- 시즌
- 에피소드
- 스페셜
- 단편/One-Shot
- 애니메이션

주요 관계 데이터:

- 세계관
- 시리즈 / 프랜차이즈
- 사가 / 페이즈
- 주연 히어로
- 정주행 루트
- 정주행 순서
- 깊이 모드 포함 여부
- 업적 관련 태그

하나의 작품이 여러 View에 포함되더라도 작품 레코드를 중복 생성하지 않고 관계 데이터로 재사용한다.

### 로컬 AI 기반 최신화

콘텐츠 DB는 사용자의 로컬 환경에서 AI를 이용해 최신화한다.

AI가 확인할 주요 변경 유형:

- 신규 작품
- 공개 예정작
- 공개일 변경
- 시즌·에피소드 추가
- 러닝타임 등 메타데이터 변경
- 한국 OTT 제공 여부 변경
- 평점/설명 등 보조 정보 갱신

권장 운영 흐름은 다음과 같다.

`정보 수집 → 기존 DB와 비교 → 변경 Diff 생성 → 검증 → DB 반영 → 변경 로그 기록`

AI가 수집한 데이터를 무검증 자동 반영하는 것보다 변경사항을 확인 가능한 형태로 관리하는 것을 우선한다.

### 대한민국 OTT 기준

OTT 정보는 한국에서 현재 합법적으로 시청 가능한 플랫폼을 기준으로 관리하고 마지막 확인일을 저장한다.

## 10. 운영 방식

초기에는 별도 회원 운영보다 콘텐츠 품질과 정주행 데이터 유지가 핵심 운영 업무다.

운영 시 주의할 항목:

- 신규/예정 작품 추가
- 공개일 연기
- OTT 이동
- 세계관·사가·히어로 분류 수정
- 시간순 정주행 순서 수정
- 깊이 모드 포함 기준 변경
- 공유 스냅샷과 현재 콘텐츠 DB의 관계 유지

분류 기준 변경이 기존 사용자의 진행률에 영향을 줄 수 있으므로 향후 변경 이력 또는 재계산 정책이 필요하다.

## 11. 기술적 고려사항

### 익명 사용자 데이터

MVP에서는 회원가입 없이 브라우저 로컬 상태와 서버의 익명 사용자 식별자를 조합하는 구조를 우선한다.

사용자가 일반 사용 중 익명 ID를 의식하지 않도록 한다.

### 공유 링크와 복구 링크 분리

- **공유 링크**: 공개 가능한 읽기 전용 스냅샷
- **복구 링크**: 실제 사용자 기록을 복원할 수 있는 비밀 링크

복구 링크는 계정 비밀번호에 준하는 민감도로 취급해야 한다. 충분한 엔트로피의 토큰, 추측 방지, 폐기/재발급 정책을 설계할 필요가 있다.

### 스냅샷 데이터

공유 스냅샷 생성 후 원본 시청 기록은 바뀌어도 스냅샷은 변경되지 않는다.

다만 작품 제목·포스터·분류 등 콘텐츠 메타데이터까지 완전히 당시 상태로 고정할지, 시청 상태만 고정하고 현재 콘텐츠 메타데이터를 참조할지는 미결정이다.

## 12. 위험 요소 및 대응

### IP·상표·저작권

**위험:** `Marvelog` 명칭의 Marvel 상표 연관성, Marvel 로고/캐릭터 이미지/영화 포스터/스틸컷/OTT 로고/외부 평점 데이터 사용 권한.

**영향:** 공개 서비스 운영 및 홍보에 직접적인 제약이 발생할 수 있다.

**대응 방향:** 정식 공개 전 서비스명과 시각 자산의 법적 사용 가능성을 검토하고, 포스터·메타데이터·평점 등 외부 데이터는 라이선스와 출처 정책을 명확히 한다.

### 콘텐츠 분류의 복잡성

**위험:** 리부트, 멀티버스, 복수 세계관, 여러 히어로/프랜차이즈에 동시에 속하는 작품 때문에 단순 트리 구조가 깨질 수 있다.

**대응 방향:** 태그·다대다 관계 중심으로 데이터 모델을 구성하고, 시간순은 반드시 세계관/루트 단위로 관리한다.

### 데이터 최신성

**위험:** 공개일과 OTT 정보가 지속적으로 변경된다.

**대응 방향:** 로컬 AI 기반 변경 탐지와 검증 가능한 Diff 워크플로우, 마지막 확인일과 변경 로그를 운영한다.

### MVP 비대화

**위험:** 작품 DB, 에피소드 추적, 업적, 공유, 비교, 추천을 동시에 구현하면 초기 검증이 늦어진다.

**대응 방향:** 핵심 가치인 체크·정주행·진행률·공유를 우선하고, 에피소드 세부 관리와 고급 게임화는 구현 계획에서 추가 축소 가능하도록 한다.

### 익명 데이터 유실 및 복구 링크 유출

**위험:** 브라우저 데이터 삭제로 사용자가 기록을 잃거나, 복구 링크가 노출되어 제3자가 기록을 가져갈 수 있다.

**대응 방향:** 서버 익명 데이터 + 복구 링크를 제공하고, 복구 토큰 재발급·폐기 정책과 사용 시 경고를 설계한다.

### 사용자가 실제로 사용하지 않을 가능성

정주행 순서를 보기만 하고 체크를 지속하지 않거나, 기존 메모/OTT 앱으로 충분하다고 느낄 수 있다.

따라서 **체크의 편의성, 즉각적인 진행률 변화, 공유하고 싶은 결과 화면**이 정보량보다 우선되어야 한다.

## 13. 결정된 사항

- 프로젝트명은 **Marvelog**로 사용한다.
- 대표 콘셉트는 **“마블, 어디까지 봤어?”**다.
- MCU에 한정하지 않고 마블 원작 기반 영화·드라마·시리즈·애니메이션 등을 전체 범위로 본다.
- 콘텐츠 범위는 3단계 정주행 깊이로 나눈다.
- 현재 깊이 모드 명칭은 `Vibranium / Mjolnir / Infinity`를 사용한다.
- 첫 진입 시 모드 선택을 강요하지 않고 바로 체크리스트를 보여준다.
- 공개순, 세계관 시간순, 히어로별, 세계관별, 사가·페이즈별, 시리즈별 등 여러 View를 제공한다.
- 히어로별 정주행은 **주연작 기준**이다.
- 기본은 포스터 그리드이며 리스트/타임라인으로 전환할 수 있다.
- 시청 상태는 `안 봄 / 보는 중 / 봄`이며 `다시 보고 싶음`을 추가한다.
- 시리즈 체크는 시즌 또는 에피소드 단위를 사용자가 선택할 수 있게 한다.
- 작품 상세에는 포스터, 제목, 공개 정보, 러닝타임, 분류, 주연 히어로, 설명, 평점, 한국 OTT 등을 제공한다.
- OTT 정보는 **대한민국 기준**으로 관리한다.
- 미시청 작품은 기본 스포일러 방지 정책을 적용한다.
- 회원가입 없는 MVP를 우선한다.
- 공유 시 닉네임을 사용한다.
- 공유 링크는 **공유 당시 상태를 고정한 읽기 전용 스냅샷**이다.
- 공유 카드를 제공한다.
- 친구와 `둘 다 봄 / 나만 봄 / 상대만 봄 / 둘 다 안 봄` 비교를 제공한다.
- 두 사람이 같이 볼 다음 작품 추천을 제공한다.
- Infinity Stone 기반 업적 시스템과 Infinity Gauntlet, 최종 100% 업적인 Stan Lee Club 방향을 사용한다.
- 공유 링크와 복구 링크를 분리한다.
- 콘텐츠 DB는 자체 구축하고 사용자의 로컬 AI를 이용해 최신화한다.
