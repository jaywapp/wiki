# Claude Code `Concise` Output Style

## 요약

Claude Code에서 출력 스타일을 `Concise`로 설정하면 기본 응답을 더 짧게 유지하고, 필요한 경우에만 상세 설명을 요청하는 방식으로 사용할 수 있다.

공유된 ClaudeDevs 게시물 기준 설정 방법은 다음과 같다.

- Claude Code에서 `/config` 실행
- `Output style` 항목을 `Concise`로 변경
- 또는 `settings.json`에 아래 설정 추가

```json
{
  "outputStyle": "Concise"
}
```

## 동작 방식

게시물 설명에 따르면 `Concise` 스타일에서는:

- 결과를 먼저 제시
- 기본 답변을 간결하게 유지
- 상세 정보는 사용자가 요청할 때 제공

즉, 작업 결과 중심으로 Claude Code를 사용하고 긴 설명을 줄이고 싶은 경우에 적합하다.

## 기대 효과

### 장점

- 터미널 출력 가독성 향상
- 코드 작업 중 불필요한 설명 감소
- 결과 확인 속도 개선
- 출력 토큰 사용량을 일부 줄일 가능성

### 주의점

`Concise`는 주로 **응답 표현 방식**을 줄이는 설정이다. 따라서 전체 토큰 사용량을 크게 줄이는 기능으로 보기는 어렵다.

토큰 사용량에는 다음도 포함되기 때문이다.

- 입력 컨텍스트
- CLAUDE.md / 프로젝트 지침
- 읽은 파일 내용
- Tool call 및 Tool result
- 대화 히스토리
- 내부 작업에 필요한 컨텍스트

따라서 `Concise`는 특히 **출력 토큰과 화면 노이즈를 줄이는 최적화**로 이해하는 것이 적절하다.

## 추천 사용 방식

일상적인 구현/수정 작업은 `Concise`를 기본값으로 두고, 설계 검토·디버깅·원인 분석처럼 설명이 필요한 경우에만 명시적으로 상세 설명을 요청하는 방식이 효율적이다.

예:

```text
원인과 판단 근거까지 자세히 설명해줘.
```

또는

```text
변경된 코드만 보여줘.
```
