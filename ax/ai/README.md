# AX / AI

AI를 활용해 개발·업무 경험을 개선하는 **Agent Experience(AX)** 자료를 한곳에 모은 인덱스입니다.

기존 `ai-workflow/`와 `ax/` 자료를 `ax/ai/` 아래로 통합하고, 문서의 성격에 따라 분류합니다.

## Categories

- `news/` — AI/에이전트 생태계의 소식·변화·업데이트
- `tips/` — 실전 설정, 문제 해결, 비용·토큰 최적화, 운영 팁
- `harness/` — 여러 모델·에이전트·도구를 조합하는 실행 하니스와 워크플로우
- `tools/` — 에이전트 도구, 프레임워크, 오픈소스 프로젝트 분석
- `skills/` — Agent Skill 및 작업 능력 확장 자료
- `research/` — 비교·검토·심층 분석 자료
- `etc/` — 위 범주에 명확히 속하지 않는 AX/AI 자료

## 분류 원칙

1. 새 제품/기능/릴리스 자체가 핵심이면 `news`.
2. 바로 적용할 설정·운영법·최적화 방법이면 `tips`.
3. 모델/에이전트를 연결해 작업 파이프라인을 만드는 내용이면 `harness`.
4. 특정 도구·MCP·프레임워크·오픈소스 프로젝트 소개/분석이면 `tools`.
5. 재사용 가능한 Agent Skill 자체 또는 Skill 비교면 `skills`.
6. 모델/제품/방법론 비교와 장문의 검토는 `research`.
7. 애매한 자료만 `etc`에 두고, `etc`가 비대해지면 새 카테고리를 만든다.

> 폴더명은 GitHub에서 정상적으로 중첩 가능한 `ax/ai/`를 사용합니다.
