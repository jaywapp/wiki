4. 초보자 추천 학습 루트

Model → Tool → Skill → Agent → Harness

Model은 두뇌, Tool은 손, Skill은 매뉴얼, Agent는 작업자, Harness는 팀 운영 체계입니다.

Tips에서 작은 성공 만들기

토큰 최적화처럼 즉시 적용 가능한 문서부터 봅니다.

Skills로 반복 업무를 표준화

Prompt Master, Humanizer, MCP Builder 등으로 AI에게 일하는 법을 가르칩니다.

Tools로 능력을 확장

Codebase Memory, Context Mode, Agent Kanban, Open Notebook 등을 탐색합니다.

Harness로 AI 팀을 설계

역할 분리, 라우팅, 컨텍스트 전달, 리뷰 구조를 익힙니다.

Research로 선택을 검증

비용·성능·운영 복잡도를 비교해 실제 도입 여부를 판단합니다.

7. 꼭 기억할 5가지

AI는 정답 기계가 아닙니다

중요한 결과는 반드시 검증합니다.

Context가 품질을 좌우합니다

많이 넣기보다 필요한 정보를 잘 고릅니다.

Tool은 권한입니다

AI가 할 수 있는 실제 행동의 범위를 결정합니다.

Skill은 재사용 자산입니다

좋은 작업 방식을 표준화합니다.

Harness는 운영 문제입니다

역할·비용·실패·검증까지 설계합니다.
