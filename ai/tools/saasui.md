# SaaSUI

SaaSUI는 Rakesh Mondal이 선별한 실제 SaaS UI/UX 패턴 라이브러리다.

## 핵심 기능
Dashboard, Onboarding, Pricing, Settings, Billing, Chat, Analytics 등 화면 패턴을 탐색한다.

## 활용
AI Coding Agent에 디자인 참고 자료로 제공하여 화면 계층과 인터랙션 요구사항을 구체화할 수 있다.

## 한계
공개 About 페이지에서 API, 코드 컴포넌트, 내부 아키텍처는 확인되지 않는다. 이미지와 로고의 권리는 원 권리자에게 있다.

## 결론
바로 적용 가능: SaaS UI 디자인 레퍼런스 조사에 적합하다.
