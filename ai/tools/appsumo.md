# AppSumo

## 한줄 요약
SaaS와 AI 도구를 할인·일회성 라이선스 형태로 발견하고 구매할 수 있는 소프트웨어 마켓플레이스.

## 개요와 해결 문제
AppSumo는 소프트웨어 개발사에 초기 고객 확보 및 유통 채널을, 구매자에게 저렴한 도구 탐색 기회를 제공한다. 홈페이지는 큐레이션된 거래, 60일 환불 약속, 구매자 리뷰를 홍보한다. 개별 거래 조건은 상품별 확인이 필요하다.

## 핵심 기능
- Lifetime Deal: 제품별 약정 범위에서 일회성 결제 사용권 제공
- 카테고리별 SaaS 탐색, 리뷰, 할인 상품 발견
- 제품 등록 및 판매자 채널, 제휴 프로그램
- AI Agent, 개발, 마케팅, 디자인 등 도구 발굴

## 구조 및 실행 흐름
이는 AppSumo 내부 구현이 아닌 **공개 서비스 기반 사용자 흐름**이다.

```mermaid
flowchart LR
  A[소프트웨어 공급사] --> B[AppSumo 상품 등록·거래]
  B --> C[구매자 탐색·리뷰]
  C --> D[결제·라이선스 사용]
  D --> E[제품 사용 및 평가]
```

내부 서비스 아키텍처, 결제 처리, API 구현은 확인되지 않음.

## 장점
- 초기 SaaS·AI 도구 발견과 경쟁 제품 벤치마킹
- 일회성 라이선스가 장기 구독 대비 유리할 가능성
- 신생 서비스의 기능·가격·포지셔닝 조사

## 단점과 한계
- Lifetime은 서비스의 영속성 보증이 아님
- 플랜별 기능, 사용량, API, 업데이트, 환불 예외 확인 필요
- 신규 제품은 안정성·보안·지원 지속성을 별도로 검증해야 함
- 자동 수집용 공식 API 제공 여부 및 허용 범위는 확인되지 않음
