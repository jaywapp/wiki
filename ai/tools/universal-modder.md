# Universal Modder

> AI Coding Agent 기반 PC 게임 모딩 툴킷

## 프로젝트 개요
Skill·CLI·지식베이스로 게임 엔진을 파악하고 모드를 작성·테스트한다.

## 해결하려는 문제
게임마다 다른 모딩 절차와 지식 단절을 줄인다.

## 핵심 기능
Skill·CLI·지식베이스로 게임 엔진을 파악하고 모드를 작성·테스트한다.

## 아키텍처
Agent Skills + um CLI + 게임별 지식베이스 + 선택적 fal/ComfyUI 에셋 생성.

## 장점
반복 작업을 자동화하고 AI Agent 워크플로우에 통합할 수 있는 가능성이 있다. 실제 효과는 별도 벤치마크가 필요하다.

## 단점 및 한계
게임별 법적 허용 범위·안티치트·저작권·외부 생성 API 비용 확인 필요.

## 활용 사례
합법적인 개인 소유 게임의 모딩 연구용 PoC.

## 기존 도구와 비교
직접 비교 벤치마크는 수행하지 않았다. 공식 기능과 제약을 중심으로 평가한다.

## 활용 아이디어
- 적용 판단: 합법적인 개인 소유 게임의 모딩 연구용 PoC.
- 도입 전 확인: 설치 재현성, 권한, Windows 지원, 운영 비용, 테스트 결과.

## 결론
AI Coding Agent 기반 PC 게임 모딩 툴킷 실무 도입 전 소규모 PoC 및 안전성 검증을 권장한다.
