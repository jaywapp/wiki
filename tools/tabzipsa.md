# TabZipsa

> AI 기반 Chrome 탭 정리 확장 프로그램

- 공식 사이트: https://tabzipsa.com/
- 대상: Desktop Chrome 116+
- 핵심 목적: 여러 창에 흩어진 탭을 한 패널에서 보고, AI가 관련 탭을 분류·그룹화·정렬하도록 지원

## 핵심 기능

### 1. 여러 Chrome 창의 탭 통합 관리
- 열려 있는 여러 Chrome 창의 탭을 하나의 사이드 패널에서 확인한다.
- 같은 이름의 그룹은 서로 다른 창에 있어도 하나의 카드로 묶어 보여준다.
- 탭을 클릭하면 해당 탭이 있는 창을 활성화한다.

### 2. AI 기반 탭 분류 / 그룹화 / 정렬
- 별도 프롬프트 작성 없이 AI 분류를 요청할 수 있다.
- AI가 열린 웹페이지를 분류하고 Chrome의 네이티브 탭 그룹으로 직접 적용한다.
- 그룹 이름 및 탭 제목 기준 정렬도 함께 수행한다.
- AI 결과는 별도의 Preview/승인 단계 없이 즉시 적용된다.
- AI 그룹화는 각 Chrome 창 내부에서 수행되며 기존 창 구조는 유지한다.

### 3. 수동 보정 및 선호 학습
- Drag & Drop으로 탭의 그룹이나 위치를 직접 수정할 수 있다.
- 로그인 상태에서는 사이트→그룹 선택 정보가 서버에 저장되어 이후 AI 분류에 활용된다.
- 그룹 해제 시 탭 자체는 닫히지 않는다.

## 데이터 / 보안 관점

AI 분류를 위해 다음 정보가 서버로 전송된다.

- 탭 제목
- 사이트 정보
- 로그인 상태에서의 사이트→그룹 선택 정보
- 계정 및 사용량 정보

기본 설정에서는 URL의 path, query string, fragment를 제외한다.

또한 Chrome History 또는 Cookie 권한을 요구하지 않으며, 페이지 내용을 읽기 위한 스크립트도 삽입하지 않는다고 설명한다.

다만 탭 제목 자체에 문서명이나 고객명 같은 업무 정보가 포함될 수 있으므로 회사 환경에서 사용할 경우 외부 AI 서비스 관련 보안 정책을 확인할 필요가 있다.

## 활용 포인트

특히 다음처럼 브라우저 탭이 업무 컨텍스트 역할을 하는 사용자에게 유용하다.

- 여러 프로젝트를 동시에 진행하는 개발자/PM
- 자료 조사를 위해 많은 문서를 열어두는 리서처
- 경쟁사/레퍼런스/보고서를 동시에 탐색하는 마케팅 업무

단순한 탭 검색 도구보다는 **현재 열려 있는 브라우저 작업 컨텍스트를 AI로 구조화하는 도구**에 가깝다.
